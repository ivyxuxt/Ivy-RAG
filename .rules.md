# Project Rules & Assumptions

## Non-negotiable constraints
- No external RAG/search library (no LangChain, LlamaIndex, Haystack, Whoosh, BM25-pt, etc.)
- No third-party vector database (no Pinecone, Weaviate, Chroma, FAISS-as-a-service)
- All similarity search: NumPy only
- All keyword search: custom BM25 (this repo)
- Mistral AI for embeddings (`mistral-embed`) and generation (`mistral-small-latest` default)
- API key in `.env` only — never hardcoded, never committed

## Upload rules
- Only `.pdf` files accepted; MIME type `application/pdf`
- Max file size: 25 MB per file
- Max files per request: 20
- Files stored under UUID on disk; original filename logged separately

## Chunking assumptions
- Target: 500 tokens (~2000 chars) per chunk
- Overlap: 75 tokens between adjacent chunks
- Minimum chunk size: 300 chars (merge smaller trailing chunks into previous)
- Heading detection: ALL-CAPS lines, lines matching `^\d+[\.\)]\s`, very short standalone lines (<50 chars)
- Never cut mid-sentence

## Retrieval defaults (all overridable via .env)
- Dense top-k (pre-fusion): 50
- BM25 top-k (pre-fusion): 50
- RRF k constant: 60
- Post-fusion top: 20 → MMR → final top 5
- MMR λ: 0.7
- Evidence gate: top-1 ≥ 0.35, avg top-3 ≥ 0.28
- Per-sentence evidence threshold: 0.50

## BM25 parameters
- k1 = 1.5, b = 0.75 (standard Okapi BM25)

## Generation
- Temperature: 0.2 (factual)
- Timeout: 30s on all outbound Mistral calls
- Max retries on 429/5xx: 3 (backoff: 2s, 4s, 8s)

## Security rules
- Never log full chunk text (PII risk) — log chunk IDs and scores only
- PII regex patterns applied to queries before any retrieval
- CORS locked to FRONTEND_ORIGIN env var
